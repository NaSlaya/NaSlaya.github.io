# Max Wright's Portfolio

A responsive, dark-themed personal IT portfolio website designed for free hosting with GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation

## Before publishing
1. Open `index.html`.
2. Find `YOUR_EMAIL@example.com` and replace it with an email address you want employers to use.
3. Review the About, Skills and Projects sections. Only keep skills and project descriptions that accurately reflect your experience.
4. The PC Research & Component Database is featured first. Add real screenshots and a link to the application when ready.
5. The Network Troubleshooting Notes and Small Automation Tool cards are marked as planned. Update them only after you have completed those projects.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com.
2. Create a new **public** repository named `your-github-username.github.io` (replace the username with your GitHub username).
3. Upload `index.html`, `styles.css`, `script.js` and this README to the repository's root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait a few minutes. Your website will be available at `https://your-github-username.github.io`.

If you use a repository with another name, the address will usually be `https://your-github-username.github.io/repository-name/`.

## Important
This is a starter portfolio template, not a claim that every example project or skill is already completed. Keep your portfolio honest and update it as you gain experience.
